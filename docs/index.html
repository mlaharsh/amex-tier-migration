03 · Evaluation

Every number is regenerated, not hand-typed.

Logistic regression is compared against a 5-fold stratified CV. The threshold is tuned on out-of-fold training predictions, then evaluated once on a holdout set.

04 · Method

The same model, exported.

The browser scorer is a client-side implementation of the trained pipeline, generated by python -m card.browser_export. The Streamlit workbench remains the full native reference.

Exported coefficients

The logistic-regression intercept, one-hot coefficients, imputer medians, and scaler parameters come directly from models/card_tier_model.joblib.

Margin economics

Annual margin per tier = (fee + interchange + interest) − (rewards + service + expected loss). The optimal tier maximizes risk-adjusted margin.

Honest evaluation

The threshold lab replays saved holdout predictions. It does not tune on the holdout set or claim production readiness.

05 · Limits

Where this should not be used.

Synthetic data, directional margins, no causal claims. Read the model card before any customer-facing use.

  • Synthetic data. This project uses a generated portfolio. Replace data/raw/card_portfolio.csv with real customer data before production use.
  • Directional margins. Annual margin estimates are illustrative, not exact P&L.
  • No causal claims. Recommending a tier migration does not guarantee margin improvement.
  • Fairness review required. Tier, income, credit score, and demographics should be audited before customer-facing use.
  • Not for underwriting. Do not use this model for credit decisions, pricing, or eligibility.
