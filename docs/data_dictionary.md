# Data dictionary — card portfolio schema

| Column | Type | Description |
| --- | --- | --- |
| customerID | string | Unique customer identifier (e.g., AMEX-0000001) |
| card_tier | categorical | Current card tier: No-Fee, Silver, Gold, Platinum, Centurion |
| tenure_months | numeric | Months as a cardmember |
| annual_fee_usd | numeric | Annual fee paid for the current tier |
| monthly_spend_usd | numeric | Average monthly card spend |
| annual_spend_usd | numeric | Annualized card spend |
| rewards_cost_usd | numeric | Estimated annual rewards cost |
| service_cost_usd | numeric | Estimated annual servicing cost |
| statement_balance_usd | numeric | Current statement balance |
| utilization_pct | numeric | Statement balance / credit limit (0–1) |
| delinquency_rate | numeric | Historical delinquency rate (0–1) |
| credit_score | numeric | Credit score (300–850) |
| income_usd | numeric | Annual income |
| age | numeric | Customer age |
| gender | categorical | M / F / Non-binary |
| region | categorical | Northeast / Southeast / Midwest / West / Southwest |
| acquisition_channel | categorical | Online / Direct Mail / Branch / Partner / Referral |
| has_premium_rewards | categorical | Yes / No |
| travel_spend_pct | numeric | Share of spend on travel (0–1) |
| dining_spend_pct | numeric | Share of spend on dining (0–1) |
| grocery_spend_pct | numeric | Share of spend on groceries (0–1) |
| digital_engagement_score | numeric | Digital engagement index (0–1) |
| support_contacts_last_12m | numeric | Support contacts in last 12 months |
| complaint_flag | categorical | Yes / No |
| Churn | binary | Target: 1 = churned, 0 = retained |

## Engineered features (used by the model)

| Feature | Definition |
| --- | --- |
| spend_to_fee_ratio | annual_spend_usd / annual_fee_usd (0 if fee is 0) |
| spend_per_tenure | annual_spend_usd / tenure_months |
| margin_proxy | (fee + interchange + interest) − (rewards + service) |
| is_premium_tier | 1 if tier is Platinum or Centurion |
| high_value_segment | 1 if annual_spend_usd ≥ 60,000 |

## Margin economics

- Interchange revenue: 1.8% of annual spend
- Interest revenue: 12% on ~50% of statement balance (revolving portion)
- Costs: rewards cost + service cost + expected loss (balance × delinquency rate)
- Annual margin per tier = revenue − costs

## Data source

This project uses a **synthetic Amex-style portfolio** generated by `card.data.generate_portfolio`. It is not real customer data. Replace `data/raw/card_portfolio.csv` with a real extract before any production use.
