04 · What this is

The same model, exported.

The browser scorer is a client-side implementation of the trained pipeline, not a new model and not a mock-up. The native Streamlit workbench remains the full reference implementation.

Exported coefficients

The logistic-regression intercept, one-hot coefficients, imputer medians, and scaler parameters come directly from models/card_tier_model.joblib.

Identical preprocessing

The browser derives the same engineered fields — spend-to-fee ratio, spend per tenure, margin proxy, premium tier flag — then applies median imputation, standard scaling, and unknown-category handling.

Honest evaluation

The threshold lab replays saved holdout predictions from the original evaluation split. It does not tune on the holdout set or claim production readiness.
